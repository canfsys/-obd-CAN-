# IoT 物联网模块 — 4G 通信桥

本目录是车载终端 **4G 通信模块**的桥接代码（银尔达物联网平台 Lua 任务），负责将 ESP32 采集到的车辆数据通过移动网络上报到云端，并接收云端下行的指令。

## 系统位置

```
┌──────────────┐   UART   ┌───────────────────────┐   HTTP/MQTT   ┌─────────────────┐
│   ESP32 固件  │◀────────▶│ 4G 模块 (espBridge.lua) │──────────────▶│ 云函数 upload   │
│ (esp32/)     │  串口协议 │ (本目录 iot/)           │   4G 网络      │ (miniprogram/)  │
└──────────────┘          └───────────────────────┘               └────────┬────────┘
                                                                           │
                                                                   ┌───────▼────────┐
                                                                   │ 微信小程序前端   │
                                                                   └────────────────┘
```

## 功能

- **UART 通信**：与 ESP32 交互，处理查询命令 `NET?` / `IMEI?` / `TIME?` / `GPS?` / `STATUS?`，返回 `KEY=VALUE` 格式数据
- **HTTP 上报**：将车辆实时状态 POST 到云端云函数 `/upload`（腾讯云开发环境）
- **MQTT 通道**：订阅 `carXXXdown` / 发布 `carXXXup` 主题，支持远程指令下行
- **GPS 透传**：模块自带 GPS 引擎，可向 ESP32 提供定位数据
- **网络透传**：4G 网络收到的数据透明转发给 ESP32

## 文件说明

| 文件 | 说明 |
|------|------|
| `espBridge.lua` | 银尔达平台 Lua 任务脚本（核心桥接逻辑） |
| `config.md` | 银尔达平台「网络通道」配置说明（HTTP/MQTT） |

## 使用前提

1. 一块支持 Lua 二次开发的银尔达（合宙系）4G 模组
2. 按 `config.md` 在平台控制台配置好网络通道
3. 将 `espBridge.lua` 上传为平台任务并启用

> 串口命令协议与 ESP32 侧 `gps_poller` / `modem_4g` 组件对应，见 `esp32/PROJECT_SUMMARY.md`。
